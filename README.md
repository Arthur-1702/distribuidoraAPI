DistribuidoraAPI
API para gerenciamento de uma distribuidora desenvolvida em Java.

Descrição
Este projeto é uma API desenvolvida para gerenciar produtos, pedidos, clientes e operações de uma distribuidora. O objetivo é oferecer uma solução robusta e escalável para o controle de estoque, vendas e cadastro de clientes.

Funcionalidades:
Cadastro, atualização e remoção de produtos
Cadastro de clientes
Gerenciamento de pedidos
Consulta de estoque

Tecnologias Utilizadas:
Java
[Spring Boot]
[PostgreSQL]
